### 🚀 Featured Engineering Architecture: [MedLink](https://github.com/jashan-nagyal4/MedLink)

> **Enterprise Computer-Aided Dispatch (CAD) & Regional Healthcare Coordination Platform**  
> Architected for real-time emergency triage, sub-35ms geospatial hospital matching using PostGIS spatial indexing, and resilient offline-first delta synchronization.

- ⚡ **Live Production Backend**: [`medlink-backend-lldt.onrender.com`](https://medlink-backend-lldt.onrender.com) (Deployed on **Render**)
- 🗄️ **Cloud Infrastructure**: **Neon Serverless PostgreSQL 16** with **PostGIS 3.6** spatial extensions (`aws-ap-southeast-1`)
- 🛰️ **Real-Time Telemetry**: **Socket.IO** state machine engine handling continuous casualty escalation and bi-directional status streams
- 🧠 **Clinical Acuity Matrix**: South African Triage Scale (SATS) algorithmic vital assessment (SpO2, HR, SBP, AVPU)

```
[🚨 Casualty Intake] ➔ [🧠 SATS Triage Engine] ➔ [📍 PostGIS Spatial Match] ➔ [⚙️ FSM Escalation] ➔ [🏥 Hospital Triage Desk]
```
